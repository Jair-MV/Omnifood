Omnifood · Web design

Style Guide

A visual reference for Omnifood’s landing page. Omnifood is an AI-powered subscription for personalized, healthy meals.

Identity and Color

Use the logo on light backgrounds. Reserve brand orange for actions and accents, and use cream tones to distinguish surfaces. Each swatch lists its original hex code and the rounded HSL value used in the CSS.

Contrast: This guide follows the original design. White on brand orange and dark orange on white fall below WCAG AA for normal text.

Use Dark Orange to highlight the hero’s delivery count: 250,000+ meals delivered last year!
